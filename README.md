# 家庭经济账

一个面向个人和夫妻家庭的收入与现金流测算工具。它既可以从税前工资正向估算家庭每月可留金额，也可以根据共同支出、储蓄目标和应急金要求，反向计算一方或双方需要达到的税前薪资。

[打开在线版本](https://personal-economy-ledger.jokerhb.chatgpt.site/)

> 在线站点为私有访问；本地版本的全部计算均在浏览器中完成。

## 主要功能

- 单人和双人家庭模式自由切换。
- 双方分别设置税前月薪、年终奖、参保地、专项附加扣除和实际缴费基数。
- 分别估算双方的五险一金、个人所得税、普通月到手和全年月均到手。
- 家庭共同管理房租、车贷、生活费等长期或阶段性支出。
- 签字费、安家费、股票和期权按所属个人、兑现比例及归属期单独计算。
- 反向计算支持“固定一方、倒推另一方”和“双方同薪倒推”。
- 家庭资金时间轴会将每月结余滚入下月，并显示累计可动用余额。
- Offer 对比可以只替换其中一方的工资，观察整个家庭现金流的变化。
- 支持本地保存、CSV 导出和打印。
- 支持下载完整 JSON 方案，再从本地加载还原测算页面。

## 保存与加载测算方案

1. 在页面上方填写“方案名称”，例如“北京双职工方案”。
2. 点击“保存方案”，浏览器会下载 `家庭经济账-方案名称-时间.json` 文件。
3. 之后点击“加载方案”，选择之前保存的 JSON 文件。
4. 检查名称、保存时间和模式，确认后会替换当前页面；若当前修改尚未保存，请先取消并保存。

方案包含双方全部收入、税费及兑现参数、共同支出、储蓄和应急金目标、期初存款、观察周期、单/双人模式、正/反向模式，以及反推和 Offer 比较对象。隐藏的伴侣参数也会保存。文件同时保留导出时的结果摘要、时间轴和 Offer 对比，方便留档；加载时依据输入重新计算，不会直接信任文件内的结果快照。后续计算规则变更可能使重算结果与旧快照不同。

文件支持在在线版本与本地版本间转移，也可存档为多个独立方案。导入仅接受本工具生成且校验有效的 JSON（最大 1 MB）；格式错误、不兼容版本或参数异常不会改变当前页面。CSV 仅供查看，不能导入还原。**方案文件含个人财务信息，未经加密，请妥善保存并谨慎分享。**

## 计算口径

收入与支出分为两层：

1. **个人收入层**：双方分别计算工资、年终奖、五险一金、个税和阶段性收入。
2. **家庭现金流层**：合并双方净收入，共同支出只扣除一次，再计算储蓄、应急金和累计余额。

系统会区分长期工资和阶段性收入。签字费、安家费只进入首年；股票和期权按归属年数分摊。反向计算中的“现金安全线”不依赖年终奖或阶段性收入。

北京和呼和浩特参数为求职决策估算预设，页面底部列有核验来源。实际结果仍会受到单位薪资结构、缴费基数、补充公积金、专项扣除归属和入职月份等因素影响。

## 快速启动（macOS）

运行前需要安装 [Node.js](https://nodejs.org/) 22.13 或更高版本。

1. 下载或克隆本仓库。
2. 双击 `启动调试.command`。
3. 首次启动会自动安装依赖。
4. 浏览器会打开 `http://localhost:3000`，修改源码后页面自动刷新。

如果 macOS 第一次阻止运行，请右键点击启动文件并选择“打开”。

## 命令行启动

npm install
npm run dev

## 数据与隐私

- 输入内容保存在当前浏览器的 `localStorage` 中，不会由应用自动上传。
- 单人旧版数据会自动迁移到新版的“本人”账户。
- 点击右上角“重置”会清除当前设备保存的测算数据。
- 保存与加载方案通过浏览器本地文件完成，不上传文件。浏览器自动记忆与下载的方案文件相互独立；重置页面不会删除已有下载文件。
- `.env`、本地构建结果、依赖目录、个人导出的 CSV 和以 `家庭经济账-` 开头的方案 JSON 已加入 `.gitignore`。如果重命名方案文件，请存放在仓库外，避免误提交。
